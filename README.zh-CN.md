WinLab 成员不用打开 portal.winlab.tw 就能查看并控制实验室。菜单跟随 portal 实时更新。

## 功能

- **控制实验室音乐**：正在播放的歌、暂停、下一首、音量和接下来的歌。
- **开门**：点一下，或用自己设置的全局快捷键。
- **显示下一次周会**：日期、报告人、地点和 Teams 链接，开始前提醒。
- **只显示需要你的事**：还没点的便当、近几天自己的会议、1 周内的公告。
- **自动更新**：经过签名与公证，用 Sparkle 更新。

## 快速开始

1. 从[最新版本](https://github.com/NYCU-WinLab/menubar/releases/latest)下载 `WinLab-<版本>.dmg`，把 WinLab 拖进「应用程序」。
2. 到 [portal.winlab.tw/api-keys](https://portal.winlab.tw/api-keys) 创建 API 密钥，勾选个人资料、点歌、开门、会议、便当、公告。
3. 打开 WinLab，在菜单选「設定 API 金鑰」，粘贴密钥。
