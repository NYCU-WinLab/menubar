WinLab 成員不用打開 portal.winlab.tw 就能看到並控制實驗室。選單跟著 portal 即時更新：換歌、便當開單、新公告，1 秒內就會出現。

## 功能

- **控制實驗室音樂**：正在播的歌、暫停、下一首、音量和接下來的歌。
- **開門**：點一下，或用自己設定的全域快捷鍵。
- **顯示下一次週會**：日期、報告人、地點和 Teams 連結，開始前提醒。
- **只顯示需要你的事**：還沒點的便當、近幾天自己的會議、1 週內的公告。
- **自動更新**：經過簽章與公證，用 Sparkle 更新；portal API 改版時也會主動找新版。

## 快速開始

1. 從[最新版本](https://github.com/NYCU-WinLab/menubar/releases/latest)下載 `WinLab-<版本>.dmg`，把 WinLab 拖進「應用程式」。
2. 到 [portal.winlab.tw/api-keys](https://portal.winlab.tw/api-keys) 建立 API 金鑰，勾選個人資料、點歌、開門、會議、便當、公告。
3. 打開 WinLab，在選單選「設定 API 金鑰」，貼上金鑰。

選單列會出現 WinLab 吉祥物，選單裡顯示實驗室正在播的歌。

## 使用

- **暫停或下一首**：歌曲下方的按鈕，或在任何 app 按 ⌃⌥⌘P、⌃⌥⌘→。
- **調音量**：拉桿，或 ⌃⌥⌘↑、⌃⌥⌘↓。
- **開門**：選單裡的「開門」；也可以到「設定… > 快捷鍵」設定快捷鍵。
- **點便當**：在選單選餐廳，選餐點和選項，按「點餐」。

## 設定

全部在「設定…」（⌘,），只有 1 頁。

| 設定 | 內容 | 預設 |
|-----|------|------|
| API 金鑰 | portal API 金鑰，存在鑰匙圈 | 無 |
| 登入時開啟 | 開機登入後自動開啟 | 開 |
| 選單列顯示歌名 | 圖示旁邊顯示正在播的歌 | 開 |
| 通知 | 新公告、便當開單、週會前 10 分鐘提醒 | 開 |
| 快捷鍵 | 全域快捷鍵；F1 到 F20 可以單獨用 | 暫停、下一首、音量 |
